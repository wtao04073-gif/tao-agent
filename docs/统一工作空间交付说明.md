# 统一工作空间交付说明

本次基于试用环境对应的 `bc01468` 源码快照重构。前台采用 Claude 聊天类产品常见的持续侧栏、中央工作流与右侧产物面板，同时保留 Tao Agent 的场景、技能、智能体、长程任务和模型选择。不是品牌复刻，也不声称已经覆盖参考产品所有功能。

## 前台完整流程

入口为 `/chat.html`，任务、场景、知识分别为 `#tasks`、`#scenarios`、`#knowledge`，对话为 `#chat`。点击导航不会跳转到旧 `/desktop/` 页面；浏览器前进和返回可切换视图。切换任务列表、场景、知识时保留当前对话 DOM、事件订阅和未提交草稿。

- **任务中心**：搜索、类型与状态筛选、打开真实会话、取消执行、新建长期任务。
- **场景**：行业分类与搜索；根据场景元数据绘制表单；文件先上传，必填与数字校验通过后真实提交任务，回到同一前台会话。
- **知识库**：上传并提取文档、查看入库状态、搜索引用片段、内容预览、移除索引、引用到当前对话。原文件在移除索引后保留。
- **对话**：保留多轮会话、长程任务、流式回答、工具过程、插话与取消；补充安全 Markdown、代码/回答复制、历史搜索和会话草稿记忆。草稿只保存在当前页面内存，不写浏览器持久存储。
- **产物面板**：DOCX/文本抽取预览、XLSX表格预览、PDF/图片受控预览、下载、继续修改。继续修改将已授权产物复制为新的引用材料，不给客户端任意服务器路径权限，不覆盖原产物。
- **移动布局**：侧栏抽屉、可关闭遮罩、单列场景表单、产物面板，输入与模型选择适配小屏。

## 独立管控端

入口为 `/control-login.html`，登录后进入 `/control/`。前台侧栏不提供管理入口。管理页面提供已有后端支持的用量、审计与时间筛选，角色由服务端检查。管控端使用单独的短期会话与浏览器 sessionStorage，不覆盖前台成员的登录身份。

当前为同一服务托管的独立应用入口，可在部署层进一步分配独立域名；本次没有把管控端伪装为已经拥有成员创建、权限策略编辑、模型在线配置等尚未实现的管理能力。管控会话在服务重启后失效，需要重新登录。

## 后端扩展与 Pi 边界

确认现有内核来自 [earendil-works/pi](https://github.com/earendil-works/pi)，锁定 `v0.87.1`。上游定位为 Agent 运行时、工具调用和状态管理，不直接提供办公产品的知识资产页面或权限化产物预览。本次复用已有 Pi Harness、工具注册、会话与事件链路，在平台层新增以下能力，未修改 vendor：

| 接口 | 作用 |
|---|---|
| `GET/POST /api/knowledge` | 当前租户工作区知识列表、搜索和入库 |
| `DELETE /api/knowledge/:id` | 创建者或授权管理员移除知识索引 |
| `GET /api/files/:name/preview` | 工作区文件安全预览 |
| `GET /api/tasks/:id/artifacts/:name/preview` | 已登记且归属当前工作区的任务产物预览 |
| `POST /api/workspace/files/reference` | 校验文件后形成对话附件引用 |
| `POST /api/workspace/artifacts/reference` | 复制有权访问的产物为后续修改材料 |
| `POST /api/control/session` | 管理员换取短期管控会话 |
| `POST /control/logout` | 撤销管控会话 |

`search_knowledge` 已装入任务工具，并加入自由办公任务白名单。所有新读取接口先验证身份和资源归属；路径要求普通文件名、工作区边界与符号链接检查；HTML/SVG/XML 以文本形式展示，不执行文件中的脚本。

## 能力与验证边界

知识入库当前支持 DOCX、XLSX和文本类文件。PDF/图片支持预览，不把无法提取文字的文件假报为已入库。XLSX预览最多展示首表的200行、50列，文本预览有长度上限；完整文件仍可下载。复杂PDF、扫描件OCR、PPT预览、原位Office编辑不属于本次新增实现，不能以“Artifacts面板已完成”代替这些能力。

代码回归：56个文件、1081项通过；自有包构建与架构边界检查通过。知识接口、跨工作区隔离、创建者删除权限、预览响应安全与管控角色检查有独立自动化覆盖。GUI环境使用确定性本地测试模型驱动真实任务和文档工具，只验证产品链路，不代表真实模型的内容生成或修改质量。GUI操作及断言结果以对应测试报告为准；断言服务返回 unknown 的项目未计为通过。界面验证中发现的小屏产物抽屉自动展开、重复导航按钮只收起不展开、管控返回入口、无会话资料预览路由及空长期任务返回问题已修正；最后这些界面修正通过脚本语法检查。小屏导航、任务打开已复验真实点击通过；知识上传、搜索、预览用例全部检查点通过。其他复合断言仍有证据不足，不能视为完整 GUI 验收通过。

## 工作区与发布

实现位于独立分支 `feat/unified-agent-workspace`，工作树 `tao-agent-workspace`。原 `tao-agent` 工作区上一轮未提交SaaS改动保留，没有被覆盖。此分支以试用站点当前版本为基线，不自动合入此前所有未发布的SaaS功能。

本轮尚未推送远端或替换用户提供的 Cloudflare 试用服务。需要将本分支变更合入运行试用站点的仓库并重启对应服务，才会在原体验地址出现新界面。当前任务不能直接控制另一个任务持有的隧道和进程。
