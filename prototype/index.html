行业通用 AI 办公 Agent 平台

面向高校服务机构与传统制造业办公管理岗的 Agent 办公工具原型。 本原型对应需求 Spec 第 4 章「页面与交互」（4.1—4.7），全部交互用原生 JS 实现， 不引任何外部依赖，双击 HTML 即可离线打开。

原型体现的 6 个关键设计决策

  • 场景卡替代空白输入框：首页是场景卡网格，自由对话入口存在但不突出
  • 任务与会话分离：任务是一等公民，全局提示条常驻，任务中心独立
  • 步骤级进度可见：显示「正在做第 3 步：核对供应商对账明细」，不是转圈 loading
  • 产出物是原生 Office 文件：.docx / .xlsx / .pptx 图标与真实文件名
  • 引用来源标注：AI 产出带来源角标，点击展开引用了哪份知识库文档
  • 修改意见回写：提交意见后沉淀为口径资产，下次同类任务自动应用

建议演示路径（3 分钟走通主链路）

  1. 打开 场景工作台，点「供应商对账核查」场景卡
  2. 表单里什么都不填直接点「提交执行」——观察必填校验拦截并列出缺什么
  3. 补齐必填项（文件可用「+ 文件名」按钮一键带入），提交 → 自动跳转会话执行页
  4. ★ 在任务执行中直接在输入框打字发送，例如「差异原因也要写清楚」 → 消息显示「已插入，将在当前步骤完成后送达」，任务不中断
  5. 等步骤跑完，出现产出物卡片（.xlsx）→ 点「预览」看保留公式的表格
  6. 点「提出修改意见」→ 填写并提交 → 提示「已记录，下次同类任务将自动应用」
  7. 去 知识资产页 切到「修改意见回写」标签，看到刚提交的意见已沉淀
  8. 去 任务中心，点状态筛选「失败」→ 进详情看失败原因 → 点「重试」
  9. 用手机尺寸打开 移动端任务列表，进会话追问并取回产物

想演示高危动作确认：在工作台选「生成 8D 质量报告」，跑到第 5 步会弹出确认卡片。
想演示失败与检查点重试：选「多系统数据核对填报」，该场景固定走失败分支。

桌面端（固定侧边导航 + 主内容区）

1280px 以上体验最佳；窄屏会自动降级为顶部横排导航
Spec 4.2 · 场景工作台（首页）

📋 场景工作台

让用户无需构思 prompt 即可发起高质量任务。首页是场景卡网格，不是一个大输入框。

  • 12 张场景卡，按行业与职能双层分组（高校 5 个 / 制造 5 个 / 通用 2 个）
  • 点击卡片 → 引导式要点收集表单，必填未齐备时阻止提交并列出缺什么
  • 行业筛选 + 关键词搜索；无匹配时引导使用自由对话
  • 首次进入空态引导（推荐 3 个最快见效场景）、最近任务、最近产出
  • 「本单位自建」标记体现租户自建场景覆盖平台预置
 Spec 4.3 · 会话执行页 ★ 最核心

💬 会话执行页

承载任务执行过程的可见化与用户追问。原型最重要的页面。

  • ★ 任务执行中输入框始终可用，消息标为「已插入，将在当前步骤完成后送达」， 在步骤边界真正送达（对应 Pi 的 steering 语义）
  • 步骤级进度卡：逐步点亮 + 显示具体当前动作 + 已产出中间物
  • 产出物卡片：预览 / 下载 / 继续修改 / 提出修改意见
  • 引用来源角标：点击展开引用了哪份知识库文档与原文片段
  • 高危动作确认卡片、等待确认态、失败态（可读原因 + 检查点重试）
 Spec 4.4 · 任务中心

📑 任务中心

统一管理所有异步任务，解决「任务与会话分离」后的可管理性。

  • 状态 / 场景筛选与排序真实过滤列表
  • 行内与批量取消 / 重试，真实改变行状态并回写共享数据
  • 任务详情：执行日志、产物、消耗（三个标签页）
  • 失败原因归类展示；并发已达上限提示含升档引导
  • 两种空态：完全无任务 / 筛选后无结果
 Spec 4.5 · 知识资产页

📚 知识资产

管理机构的文档知识库、模板与口径资产——产品的核心差异化能力。

  • 文档上传演示解析中 → 已就绪 / 解析失败（含原因与重试）状态流转
  • 权限设置弹窗体现读写分离的权限矩阵；四级资产范围
  • 权限不足提示区分「完全不可见」与「可见但不可编辑」
  • 模板库（含同名模板被高优先级覆盖）、字段口径定义表
  • 修改意见回写列表（会合并你在会话页刚提交的意见）、版本与变更记录
 Spec 4.6 · 管理后台

⚙️ 管理后台

租户管理员的组织、权限、技能、用量与模型配置入口。

  • 用量与产出看板：纯 CSS 堆叠柱状图 + 内联 SVG 折线图，不引任何图表库
  • 成员角色表（角色下拉可改，即时生效并写审计）、单用户熔断与解除
  • 技能包管理（三级命名空间、启停即时生效）、场景卡管理、工作区管理
  • 模型分层路由与热替换、回归评测门禁（可点击运行）
  • 配额与并发（升档引导）、可检索的审计日志

移动端 Web

375px 基准，触摸友好；不支持的复杂操作明确引导至桌面端
Spec 4.7 · 移动端任务列表

📱 任务列表（移动端）

移动场景下的查看与取回入口。

  • 与桌面端共享同一份任务数据（浏览器本地存储）
  • 横向滚动的状态筛选条，点击区 ≥ 40px 高
  • 任务完成通知；产物可取回标记
  • 明确标注「发起复杂任务与管理后台请用桌面端」
 Spec 4.7 · 移动端会话追问

📱 会话追问（移动端）

小屏下的进度查看、追问与产物取回分享。

  • 进度压缩为「当前动作 + 进度条 + 可展开的步骤列表」
  • 执行中同样可追问，排队送达语义与桌面端一致
  • 产物取回 / 分享链接 / 转发；编辑与口径回写引导至桌面端
  • 高危动作确认、失败重试在移动端同样可完成

原型说明

技术栈
纯静态 HTML + CSS + 原生 JS，零外部依赖，可离线打开
主题
浅色 / 深色双主题，跟随系统偏好，右上角按钮可手动切换
数据
演示数据存于浏览器 localStorage，桌面端与移动端共享同一份
内容
全部使用两个目标行业的真实业务叫法，无占位假文
可访问性
语义化标签、focus 可见、aria 状态、跳转主内容链接、尊重减少动效偏好
